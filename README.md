# K44TER website starter

Responsive static site with Home, Music, Videos, Merch, About and Contact pages.

Open index.html in a browser. All pages work as local files.

## Add approved media later
- Add approved cover artwork and audio to assets/releases/.
- Add approved video thumbnails and links to assets/videos/.
- Add approved product photos and details to assets/merch/.
- Replace labeled pending blocks in the matching page with supplied assets and details.
- Do not add release dates, track names, prices, view counts, payment, embeds or forms until the actual details and setup are provided.

The cosmic banner artwork is at least 1K resolution and contains no person or logo. The logo used by the site comes from the new chrome logo image supplied with the page layouts. The original layout references have not been changed.
